## 正文

**先上图（贴 docs/demo.gif）**

不知道你们有没有这个习惯：用 API 版的 AI 客户端，碰到翻译个词、算个日期、闲聊两句这种简单问题，总觉得用 token 有点浪费，但切到浏览器开网页版又麻烦。

所以我写了个开源小工具，给 DeepSeek Harness Desktop 加了个左侧栏「网页版」按钮：

- 点击按钮 → 主区域直接打开 chat.deepseek.com
- 再点一下（或点「新对话」）→ 关闭网页版，回到 API 对话
- 网页版独立登录、独立会话，和 API 对话互不干扰
- 按钮名称、网址都能自定义

**技术上有个坑**：chat.deepseek.com 返回 `frame-ancestors 'none'`，普通 iframe 会被浏览器直接拦掉。所以没走 iframe，而是用 Electron 原生 `WebContentsView`（就是这些客户端加载自己界面的那套机制），绕开了 CSP 限制。

**顺带做了点设计**：把核心逻辑抽成了零依赖的通用模块 `lib/web-switcher.js`，理论上任何 Electron AI 客户端都能三步接入，不限于 DeepSeek Harness。写了移植指南，欢迎 PR 适配器。

仓库地址：https://github.com/caiyaoxin/ai-desktop-web-switcher

MIT 协议，Windows 一键安装（`install.ps1`），有卸载脚本可完整还原。

求个 star，也欢迎大家提 issue / 贡献适配器。
